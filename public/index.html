Client Integration Specification

API endpoints for payload distribution and KeyAuth client authentication

1. Direct Binary Streaming (Zero-Name Link)

Streams the raw binary payload directly without exposing the original filename in the URL path:

GET https://<domain>/api/:token

2. KeyAuth v1.2 Protocol

Standard KeyAuth request format compatible with C++, C#, Python, and CLI loaders:

// Initialize Session
GET https://<domain>/api/1.2/?type=init&name=ApexSecurity&secret=apex_secret_key_999

// Authenticate License Key + Hardware ID Lock
GET https://<domain>/api/1.2/?type=license&key=APEX-XXXX-XXXX-XXXX&hwid=USER_HWID_STRING

3. REST JSON License Verification

POST https://<domain>/api/v1/license/verify
Content-Type: application/json

{
  "key": "APEX-XXXX-XXXX-XXXX",
  "hwid": "0123-4567-89AB-CDEF"
}
